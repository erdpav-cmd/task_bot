# 📋 Task Bot - Telegram-бот для управления задачами

## Описание

Telegram-бот для создания и управления задачами. Позволяет добавлять, просматривать и удалять задачи прямо из мессенджера.

## Возможности

- ✅ Создание новых задач
- 📝 Просмотр списка задач
- ❌ Удаление выполненных задач
- 💾 Хранение данных в SQLite
- 🔐 Индивидуальная настройка для каждого пользователя

## Технологии

- Python 3.10+
- aiogram (Telegram Bot API)
- SQLite (база данных)
- asyncio
