Создай проект на Python:
- Telegram-бот для командной работы, для добавления задач в общий список, используй aiogram для создания tg бота.
- Интерфейс: бот принимает команды (/start, /add, /list, /list_csv).
- Логика: обработка сообщений, добавление задач, вывод списка, вывод списка файлом в формате CSV.
- Данные: SQLite3 (таблица tasks: id, text, user, created_at).
- Минимальный рабочий пример:
    1) /start — приветствует.
    2) /add — сохраняет задачу в базу.
    3) /list — выводит все задачи.
    4) /list_csv — отправляет CSV-файл с задачами пользователю.
- Структура проекта:
создай файл main.py (точка входа);
все роуты, взаимодействие с БД, клавиатуры и т.д. — раздели по разным пакетам.
Требования к коду:

Код должен быть простым, с комментариями для новичков.
